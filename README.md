## 🚀 Getting Started Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Natalia-cherry/nataliacherono.github.io.git
   ```
2. Open the folder:
   ```bash
   cd nataliacherono.github.io
   ```
3. Open `index.html` in your browser — no server needed!
